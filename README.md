# Webrender Library Desk — releases

Downloads for **Webrender Library Desk**, your Webrender Library as a program on your own
computer — the same Library in a window of its own, with the prints you download landing in a
folder on your computer — and **Webrender**, the purple W, a small launcher for the Webrender
programs, from Nextwaveweb Ltd. It needs a Webrender account. What it is, the download link and
what to expect on first run are on its page:

**https://nextwaveweb.co.uk/products/webrender-library-desk**

This repository holds no source code — only the released builds: one GitHub Release per
version, with the download as its asset. Every download carries a README (what you need, setting
up, signing in, the first-run warning, removal) and a `THIRD-PARTY-NOTICES.txt` listing the
open-source components both programs are built from — `README.txt` beside the programs in the
Windows zip.

Windows is at 0.1.0. macOS and Linux follow.
